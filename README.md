# lostlantern.co.za

The Lost Lantern Digital website: plain HTML and CSS, no build step.

- `index.html`: the main site (lostlantern.co.za)
- `morrow/index.html`: the Morrow page (lostlantern.co.za/morrow/)
- `styles.css`, `morrow.js`, `favicon.svg`, `404.html`

Hosted on Netlify: every `git push` publishes it.
